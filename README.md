# 🎬 Movie Information Page

A simple and clean **Movie Information Page** built using **HTML5 and CSS3**.
This project was created as part of my web development practice to improve my understanding of webpage structure, tables, images, sections, and CSS styling.

## 📌 Project Overview

**The Last Journey** is a fictional movie information page designed to display important details about a movie in an organized and user-friendly format.

The page presents information such as the movie genre, release year, language, and other movie-related details.

## 🌐 Website Sections

The Movie Information Page includes:

* **Movie Title** – Displays the movie name

## 🚀 How to Run the Project

### Method 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The webpage will open in your browser.

### Method 2 — Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Run it using a browser or Live Server.
4. The Movie Information Page will open.
